Forecasts every Grand Theft Auto VI PlayStation 5 trophy's earn rate on Exophase at 2026-11-26T00:00:00Z. A Python 3.13 standard-library-only program: it models Exophase's refresh dilution (tracked players jump, rates fall), per-trophy unlock trends against log-time, and player-base growth, and writes five quantiles per trophy.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
